# Task_4
📱 Project Goal
Convert a desktop webpage to mobile-responsive using CSS media queries.

🛠️ Tools
HTML/CSS

VS Code

Chrome DevTools

✅ Key Changes Made
Layout
Stacked columns vertically on mobile

Replaced fixed widths with flexible units (%)

Adjusted padding/margins for small screens

Navigation
Converted horizontal menu to vertical stack

Increased tap target sizes (min 44px)

Content
Scaled down font sizes

Made images responsive (max-width: 100%)

Fixed overflow issues

Media Query
css
@media (max-width: 768px) {
  /* Mobile styles */
}
🧪 Testing
Chrome DevTools device simulation

Verified no horizontal scrolling

Checked touch-friendly interactions

📱 Outcome
Website now works seamlessly on both desktop and mobile devices.
